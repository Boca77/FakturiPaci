# Пачи — програми

Три мали програми на едно место. Работат во интернет-прелистувач (Chrome, Edge, Firefox).
Нема инсталација.

## Како се отвора

Кликни двапати на **`index.html`** во оваа папка. Ќе се отвори страница со три полиња —
избери го она што ти треба.

Во секоја програма горе лево има копче **„← Назад“** за враќање на почетната страница.

## Што има внатре

| Папка | Што прави |
|---|---|
| [`fakturi/`](fakturi/) | Прави фактура за клиент и ја зачувува како PDF |
| [`etiketi/`](etiketi/) | Прави PDF со етикети F-19 (63.5 × 46.6 mm, 18 по А4) |
| [`sliki/`](sliki/) | Наместува слики во точна големина во см/мм за печатење на А4 |

Подробно упатство за програмата со сликите има во [`sliki/README.md`](sliki/README.md).

## Технички забелешки

- Сè е обични HTML/CSS/JS датотеки — нема сервер, нема сборка (build).
- Секоја програма е самостојна во својата папка; надворешните библиотеки се
  повлекуваат од CDN, па за фактурите и етикетите е потребен интернет при првото отворање.
  Програмата за слики работи и без интернет.
- Фактурите чуваат список на продукти во Firebase Firestore. Конфигурацијата е во
  `fakturi/index.html`. Firebase клучот е јавен по дизајн (се гледа во прелистувачот) —
  заштитата се прави преку Firestore security rules, не преку криење на клучот.
